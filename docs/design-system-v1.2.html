2.13 Usage rules consolidated from May 2026 audit NEW

Inline footnotes throughout §2.1–§2.5 reference these by ID (R1, R2…). Designers and devs should read these once to understand the “why” behind the token values and how to use them correctly.

  • R1Lime button text
    Primary fill buttons MUST use dark text #121212 (token: colorTextBase). Never white on lime — fails contrast at 2.32:1. Dark on lime passes 8.07:1 (AAA).
  • R2Status FILL vs TEXT split
    colorError / colorWarning / colorSuccess are FILL only (badges, banners, status pills). For text use colorErrorText / colorWarningText / colorSuccessText. Never use base status as standalone text on light bg — success fails 2.17:1, warning fails 1.82:1.
  • R3Lime as text or border
    Use colorPrimaryText (#5B7611 light / #C3E165 dark), NOT colorPrimary (#8FB821). Base lime as text fails AA at 2.22:1. colorPrimaryText passes 4.97:1 in light, 11.29:1 in dark.
  • R4Border philosophy (kept Ant-subtle)
    Default border-primary is intentionally subtle (~1.4–1.8:1 against surfaces). State communication relies on label + fill + focus state, not border alone. When 3:1 UI contrast is critical (active selection, focus ring), use colorPrimaryBorder instead.
  • R5Surface hierarchy intentionally subtle
    Adjacent surface layers in light mode sit at 1.04–1.09:1 luminance ratios. Depth comes from luminance shift, not heavy contrast. Don’t add borders or shadows trying to force more separation.
  • R6Intentional hex collisions
    Light: colorPrimaryActive = colorPrimaryText (both #5B7611). Dark: colorPrimaryBorder = colorPrimaryText (both #C3E165). Different properties on different elements — no visual conflict possible. Documented here so they’re not flagged as bugs.
  • R7Off-white bgBase, not pure white
    Main content surfaces use #FAFAF7 (warm off-white), never #ffffff. Pure white is reserved for elevated surfaces (modals, dropdowns) so they visibly float above the content layer. Studio Alpha aesthetic.
  • R8Bg-spotlight is a light surface tier
    colorBgSpotlight = #F0F0EC light / #1B1B1F dark. It’s for table headers, wells, alt rows, secondary panels — NOT for tooltip overlays. For tooltip dark overlays use inline rgba(0,0,0,0.85).
  • R9Text-tertiary now passes AA body
    May 2026 bumped text-tertiary opacity from 0.45 to 0.55. Now usable for body text, paragraph copy, metadata, hints. Maintains 1.55:1 distinctness from text-secondary — clearly perceivable gap, no hierarchy collapse.
